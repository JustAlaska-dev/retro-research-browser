# Retro Research Browser

A retro-styled Chromium-based web browser built with Python and PySide6, designed to make web research easier to organize and manage.

## 🖥️ About the Project

Retro Research Browser combines a classic 1960s-inspired visual design with modern web browsing and research organization tools.

The goal is to create a browser that doesn't just display webpages, but helps users collect, organize, and revisit information while researching a topic.

## ✨ Features

- 🌐 Chromium-based web browsing
- 📑 Multi-tab browsing
- 📚 Research Board for organizing webpages
- 🗂️ Multiple customizable research columns
- 📝 Research notes
- 🖱️ Drag-and-drop organization
- 💾 Persistent research-board storage
- 🔗 Save webpages directly to the Research Board
- 📺 Retro television-inspired interface
- 🐼 Red panda-themed interface elements

## 🛠️ Built With

- Python
- PySide6
- Qt WebEngine / Chromium
- JSON
- Git & GitHub

🚀 How to Run

Clone this repository, install the required Python dependencies, and run main.py to launch the Retro Research Browser.

git clone https://github.com/JustAlaska-dev/retro-research-browser.git
cd retro-research-browser
pip install -r requirements.txt
python main.py

No additional setup is required.
